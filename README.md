# 🌿 MindEase AI Companion

**MindEase AI** is an empathetic, mood-aware Mental Health AI Companion designed specifically to support youth. It provides a safe, non-judgmental space for users to express their feelings, leveraging **Retrieval-Augmented Generation (RAG)** to deliver verified wellness strategies and emotional support.

Unlike standard chatbots, MindEase is grounded in a curated database of mental health resources, ensuring that its suggestions for coping mechanisms, breathing exercises, and CBT techniques are based on **trusted content**, not generic AI patterns.

---

## 🚀 Key Features

### 💭 Mood Detection & Reflection  
Automatically analyzes the user's emotional tone and responds with empathy and personalized reflection.

### 📚 RAG-Powered Wellness  
Dynamically retrieves context from professional wellness PDFs to provide **specific, actionable coping strategies**.

### 🎨 Youth-Centric UI  
A calming React-based interface featuring the **MindEase Leaf** icon and a soothing green color palette.

### 🛡️ Safety & Crisis Guardrails  
Detects crisis-related language and provides immediate access to professional resources like the **988 Lifeline**.

### ✨ Clean Markdown Responses  
Uses structured Markdown formatting (headers, bold text, lists) for easy readability and clarity.

---

## 🛠️ Tech Stack

### 🧠 Backend (The Brain)

- **Python / Flask** – Lightweight API server  
- **LangChain** – Orchestrates the RAG pipeline and prompt logic  
- **Google Gemini 2.5 Flash** – Core LLM for empathetic reasoning  
- **ChromaDB** – Local vector database for document storage  
- **HuggingFace Embeddings** – `all-MiniLM-L6-v2` for vector generation  

### 🎭 Frontend (The Face)

- **React 18** – Responsive single-page application  
- **Tailwind CSS** – Modern, fluid UI styling  
- **Marked.js** – Renders Markdown responses into clean HTML  

---

## 🧠 Core Operating Principles

- **Mood Detection First**  
  Always acknowledge the user’s emotions.  
  _Example: “I can feel how much pressure you're under…”_

- **Grounded Knowledge**  
  Prioritize strategies retrieved from uploaded documents over general LLM knowledge.

- **Youth-Centric Tone**  
  Supportive, warm, and conversational — never clinical.

- **Privacy & Safety**  
  MindEase is a supportive companion, **not a therapist**.

---

## ⚠️ Safety Disclaimer

> MindEase AI is not a medical professional or a replacement for clinical therapy.  
> It is a supportive tool designed for emotional reflection and wellness education.
